# Fuentes

Coloca aquí los archivos de **Albra Regular** (fuente comercial, no se puede descargar de Google Fonts):

- `Albra-Regular.woff2`  (recomendado)
- `Albra-Regular.woff`
- `Albra-Regular.otf`    (o `.ttf`)

Con que exista uno es suficiente. Mientras no estén, el sitio usa *Playfair Display* como respaldo.

**Space Mono** se carga automáticamente desde Google Fonts.
